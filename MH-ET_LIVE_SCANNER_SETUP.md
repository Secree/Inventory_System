# 🔴 MH-ET LIVE Scanner Setup Guide

Quick setup guide for using MH-ET LIVE and similar USB handheld scanners with the Water Gallon Inventory System.

## 📦 What You Need

- **MH-ET LIVE USB Handheld Scanner** (or compatible USB QR/barcode scanner)
- Raspberry Pi (or Windows PC)
- USB port (scanner uses USB-A connector)

## ⚡ Quick Start (Raspberry Pi)

### 1. Plug In Scanner
```bash
# Simply plug USB scanner into any USB port
# No drivers needed - works as USB keyboard (HID)

# Verify detection
lsusb
# Should show: "Symbol Technologies" or similar USB device
```

### 2. Test Scanner
```bash
# Open any text editor
nano test.txt

# Press scanner button (red light appears)
# Scan any QR code (white light when detected)
# Data should appear in text file

# If data appears, scanner is working! ✅
# Press Ctrl+X to exit nano
```

### 3. Launch Application
```bash
cd ~/Inventory_System
python3 main.py
```

### 4. Use Scanner
1. Go to **"Add/Scan"** tab
2. Click in the **yellow input field** (under "🔴 Handheld Scanner")
3. Point scanner at QR code
4. Press scanner button
5. Action dialog opens automatically!

## 🪟 Quick Start (Windows)

### 1. Plug In Scanner
- Connect USB cable to computer
- Windows auto-detects as keyboard
- No driver installation needed
- Look for "USB Input Device" in Device Manager

### 2. Test Scanner
- Open Notepad
- Press scanner button and scan QR code
- Data should appear in Notepad
- If working, you're ready!

### 3. Launch Application
```batch
# Double-click run.bat
# Or run from terminal:
.\run.bat
```

### 4. Use Scanner
Same as Raspberry Pi instructions above!

## 🎯 How It Works

### Scanner Operation
```
Press Button → Red Light ON → Point at QR → White Light (detected) 
→ Data sent to computer → Auto-press Enter → Done!
```

### Data Format
Your QR codes contain:
```
INVENTORY_ID:WG-0001|NAME:Blue Container
```

The scanner:
1. Reads this text from QR code
2. "Types" it as if you typed on keyboard
3. Presses Enter key
4. Application processes it automatically

### Auto-Processing Flow
```
Scanner Input → Parse Data → Find in Database → Show Action Dialog
                     ↓
          (Refill / Defect / Fix / Leak Test)
```

## 🔧 Troubleshooting

### Problem: Scanner Not Detected

**Raspberry Pi:**
```bash
# Check USB devices
lsusb

# Should see scanner device
# If not, try:
sudo reboot

# After reboot, check again
lsusb
```

**Windows:**
- Open Device Manager (Win+X → Device Manager)
- Look under "Keyboards" or "USB Input Devices"
- Should see scanner device
- If not, try different USB port

### Problem: Scanner Reads but Data Not Appearing

**Check 1: Field Focus**
- Make sure yellow input field has cursor (blinking line)
- Click field before scanning

**Check 2: Test in Text Editor**
```bash
# Raspberry Pi
nano test.txt
# Scan QR code - does data appear?

# Windows
# Open Notepad
# Scan QR code - does data appear?
```

**Check 3: Permissions (Pi only)**
```bash
# Add user to input group
sudo usermod -a -G input $USER

# Logout and back in
exit
```

### Problem: Wrong/Garbled Characters

**Solution: Check Keyboard Layout**

**Raspberry Pi:**
```bash
sudo raspi-config
# → Localisation Options → Keyboard Layout
# Set to US (English US)
```

**Windows:**
- Settings → Time & Language → Language
- Set to English (United States)
- Or match your scanner's default layout

### Problem: Scanner Beeps but Nothing Happens

**Possible Issues:**
1. **QR code format wrong**
   - Must be generated by this application
   - Format: `INVENTORY_ID:WG-####|NAME:...`

2. **ID not in database**
   - Scanner reads QR but ID doesn't exist
   - Add gallon first, then scan

3. **Field not focused**
   - Click yellow input field first

4. **Scanner in wrong mode**
   - Must be in USB-HID (keyboard) mode
   - Check scanner manual for mode setting

## 📋 Scanner Configuration

Most scanners ship ready to use, but you can configure:

### Enable Enter Suffix (Required)
Scanner must press Enter after scanning. Usually default.
Check manual for "Suffix" or "Terminator" settings.

### USB-HID Mode (Required)
Scanner acts as keyboard. Usually default for USB models.
Alternative modes: RS232 Serial, USB-COM (don't use these)

### Beep Settings (Optional)
```
Scan config barcode from manual to:
- Adjust beep volume
- Enable/disable beep
- Change beep tone
```

### Scan Mode (Optional)
- **Trigger mode**: Press button each time (recommended)
- **Continuous mode**: Hold button once, scan multiple
- **Auto mode**: Always scanning (drains battery)

## 🚀 Pro Tips

### Rapid Scanning
1. Click yellow field once
2. Scan → Choose action → Scan again
3. Field stays focused - no need to click again
4. Process 20+ gallons per minute!

### Optimal Scanning
- **Distance**: 5-20 cm from QR code
- **Angle**: Straight on or slight angle
- **Lighting**: Scanner has built-in light, but ambient helps
- **Cleanliness**: Keep QR codes and scanner lens clean

### Multi-Scanner Setup
- Can connect multiple scanners
- Each works independently
- Great for multi-user workstations
- All send to focused input field

### Battery Models (Bluetooth)
If using wireless scanner:
- Charge before use (usually 1-2 hours)
- Battery lasts 8-12 hours typically
- Can use while charging
- Pair via Bluetooth settings
